## Your agent workspace

Each factory groups the agents and activity for a project. Switch between factories in the sidebar to see the project's dashboard, agents, runs, and pull requests.

Open an agent to read its instructions, inspect previous runs, or continue its live conversation. Schedule controls let you pause, resume, or run an agent when you need it.

## Runs on your computers

OpenFactory owns your schedules, webhooks, and conversations, and starts sessions directly in Codex CLI or Claude Code CLI. T3 Code is not required.

Keep the OpenFactory runtime running for scheduled work to start. A successful run means the provider completed its turn; open the conversation to inspect its output.

## Configuration as code

Agent definitions combine YAML configuration with Markdown instructions. The [factory definition reference](/docs/factory-definition) describes the file format and identifies which parts OpenFactory supports.

The reference also includes Warp's broader factory format. Its compatibility section distinguishes those fields from the behavior available in OpenFactory.
