# Gardening operating policy

Configure the canonical repository/checkout and backing repository, state directory,
target revision, review phases and local times, timezone, per-run time budget,
priorities, notification route and authority, environment setup skill, backup status
and ownership. Use the project's existing domain glossary and architecture decisions.

Runtime dossier and generated reports live outside the reusable skill. Configure
Git ignores before initialization. The skill owns its references and report templates.
Permit source/history inspection and dossier/report updates; separately authorize
refactoring, messaging, scheduling or external effects when needed.
